# MedicalAI Client

This is the client-side application for MedicalAI.

## Features

- User authentication
- Medical data visualization
- AI-powered diagnostics

## Getting Started

1. Clone the repository:
    ```bash
    git clone https://github.com/yourusername/MedicalAI.git
    ```
2. Navigate to the client directory:
    ```bash
    cd MedicalAI/client
    ```
3. Install dependencies:
    ```bash
    npm install
    ```
4. Start the development server:
    ```bash
    npm start
    ```

## Technologies Used

- React
- Node.js
- Express
- TensorFlow.js
